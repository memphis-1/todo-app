# 待办清单

一个用原生 HTML、CSS 和 JavaScript 写成的待办清单网页：可添加任务、标记完成、删除任务，数据保存在浏览器本地。

[English](README.en.md)

## 功能

- 输入任务内容后点击「添加」或按回车，即可新增任务
- 勾选任务左侧的复选框，标记为已完成（显示删除线）
- 点击右侧「×」删除任务
- 顶部显示待完成数量和任务总数
- 列表为空时显示引导提示
- 任务写入 `localStorage`，刷新页面后仍会保留

## 使用方法

用浏览器直接打开 `index.html` 即可，无需安装依赖，也无需启动服务器。

任务最长 120 个字符；空白内容不会被添加。

数据保存在当前浏览器的本地存储中（键名：`todo-app-tasks`）。更换浏览器、清除站点数据或使用无痕模式后，记录可能消失。

## 技术说明

纯前端静态页面，不依赖框架或构建工具。交互通过表单提交、复选框变更和删除按钮点击完成；页面渲染时根据本地存储中的任务列表更新界面。
